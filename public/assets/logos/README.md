# Loggor

Meritlys symbol är skapad för webbplatsen. Anordnarnas SVG-loggor kommer från Simple Icons (CC0), version 13.21.0; IBM från version 11.15.0.

Källa: https://github.com/simple-icons/simple-icons
Licens: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Varumärken tillhör respektive ägare. Loggorna används för att identifiera utbildningsanordnare och innebär inget samarbete eller godkännande.
